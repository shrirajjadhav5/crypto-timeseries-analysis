# CryptoVision AI ₿
**Cryptocurrency Time Series Intelligence System**

A comprehensive analytical framework that transforms historical market data into structured forecasting intelligence. 

## 🚀 Features
- **Triple-Model Pipeline:** Statistical (ARIMA), Deep Learning (LSTM), and Additive (Prophet) forecasting.
- **Risk Metrics:** Automated calculation of Sharpe Ratio, Max Drawdown, and Volatility.
- **Visual Dashboard:** Interactive HTML visualization for multi-asset comparison.

## 🛠️ Tech Stack
- **Languages:** Python (Pandas, NumPy, Scikit-learn)
- **DL Frameworks:** TensorFlow/Keras
- **Forecasting:** Statsmodels, Facebook Prophet
- **Frontend:** Chart.js, HTML5

## 📊 Performance
The system evaluates assets (BTC, ETH, SOL, BNB, ADA) and generates 30-day forecasts.
- **LSTM:** Captures non-linear volatility.
- **ARIMA:** Provides statistical baseline trends.
